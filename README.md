📊 E-Commerce Sales and Customer Analytics

📌 Project Overview

The E-Commerce Sales and Customer Analytics project analyzes sales data and customer behavior to identify meaningful business insights. The project uses Python for data cleaning, exploratory data analysis, and visualization, along with Power BI for creating an interactive dashboard.

⸻

🎯 Project Objectives

* Analyze overall sales performance.
* Identify high-performing product categories.
* Analyze sales across different regions.
* Understand customer purchasing behavior.
* Analyze payment method preferences.
* Study product returns.
* Analyze profit margins and delivery performance.
* Create an interactive Power BI dashboard.

⸻

🧹 Data Preparation

The following data preparation steps were performed:

* Checked dataset structure and data types.
* Checked for missing values.
* Checked for duplicate records.
* Generated descriptive statistics.
* Cleaned column names.
* Converted the order date column to datetime format.
* Checked numeric values and outliers.
* Saved the cleaned dataset.

Result: No missing values and no duplicate records were found.
